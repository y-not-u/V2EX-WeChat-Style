# V2EX 微信聊天皮肤 (v2ex-wechat-style)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.9-blue.svg)](https://www.typescriptlang.org/)
[![Playwright](https://img.shields.io/badge/Playwright-E2E%20Passed-green.svg)](https://playwright.dev/)
[![Tampermonkey](https://img.shields.io/badge/Tampermonkey-Supported-black.svg)](https://www.tampermonkey.net/)

通过 Tampermonkey 用户脚本，将 V2EX 桌面网页重构为微信桌面端风格的经典三栏界面。

左侧功能导航，中间话题列表，右侧聊天式气泡呈现正文与回帖；自己发送的消息以绿色气泡展示。直接复用 V2EX 原站内容与浏览器登录 Cookie，无需 API Key 或独立中间服务器，保障隐私安全。

## 特性一览

- 💬 **微信经典三栏交互**：左侧图标导航栏 + 中间话题列表 + 右侧沉浸式聊天对话窗口。
- 🟢 **聊天气泡呈现**：楼主正文与附言置顶展示，各楼层回帖以气泡消息排列；本人回复采用右侧绿色气泡。
- ⚡ **单页无刷新体验**：话题与分页局部按需加载，平滑切换，完整支持浏览器“前进 / 后退”历史记录。
- 🔒 **本地安全与隐私**：
  - 纯前端脚本运行，无任何第三方服务器或中转代理。
  - 集成 **DOMPurify** 严格过滤 XSS 与危险属性；集成 **marked** 渲染 Markdown。
- 📝 **智能防丢草稿**：
  - 回复草稿按 `用户账号 + 话题 ID` 隔离存储。
  - 发帖草稿按 `用户账号` 独立暂存。
  - 仅保存在油猴扩展本地存储（`GM_setValue`），发送失败或意外关闭均不丢失。
- ⌨️ **便捷键盘操作**：支持 `Ctrl+Enter` / `Cmd+Enter` 发送消息，点击用户名快捷 `@`。
- 💰 **原站金币操作保护**：感谢作者或感谢回帖前弹出确认提示与金币消耗说明，防止误触。
- 🎛️ **无缝切回原版**：内置一键切回原版按钮；通过 URL 参数 `?v2wc=off` 可随时单次停用皮肤。

## 安装使用

### 前置要求
- 浏览器：桌面端 **Chrome** / **Edge** / **Firefox** 等（视口宽度建议 ≥ 1024px）。
- 扩展：已安装 [Tampermonkey (油猴)](https://www.tampermonkey.net/)，并根据浏览器提示启用“允许访问文件网址”或开启开发者模式。

### 安装步骤

#### 方式 A：一键在线安装（推荐）
1. 确保已安装 Tampermonkey 扩展。
2. 点击此链接：👉 **[点击一键安装脚本 (Raw)](https://raw.githubusercontent.com/y-not-u/V2EX-WeChat-Style/main/v2ex-wechat.user.js)**。
3. Tampermonkey 会自动捕获并弹出安装确认界面，点击 **“安装”** 即可。后续还会支持自动检查更新。

#### 方式 B：手动复制粘贴
1. 打开 [v2ex-wechat.user.js](./v2ex-wechat.user.js) 并复制全部内容。
2. 点击 Tampermonkey 扩展图标 → **“管理面板”** → **“+ (添加新脚本)”**。
3. 清空编辑器中的模板代码，粘贴复制的完整内容并按 `Ctrl+S` 保存。

#### 开始使用
打开或刷新 [https://www.v2ex.com/](https://www.v2ex.com/)：
- 若已登录，皮肤将自动沿用登录态，支持发帖、回复、收藏和感谢。
- 若未登录，可正常浏览公开话题；敏感操作会引导至原站登录。

## 交互与快捷键

### 快捷键
| 操作 | 快捷键 / 触发方式 | 说明 |
| :--- | :--- | :--- |
| **发送回复** | `Ctrl + Enter` 或 `Cmd + Enter` | 提交当前回复输入框内容 |
| **换行** | `Enter` | 输入框正常换行 |
| **快捷 @ 用户** | 点击楼层用户名或“回复”按钮 | 自动在输入框光标处插入 `@用户名` |
| **切换原版/皮肤** | 点击左下角退出图标 | 或在油猴菜单选择“恢复原站界面” |
| **临时原站模式** | 访问任意链接追加 `?v2wc=off` | 当前标签页保持原站显示 |

### 核心功能操作
- **浏览**：点击左侧列表话题，右侧局部加载正文与楼层评论；支持分类切换、节点筛选、个人收藏列表及评论分页。
- **发帖**：点击中间列表右上角 `+` 号唤起新话题面板，支持节点搜索、正文 Markdown 实时预览。
- **图片与代码**：聊天中图片适度缩略显示，点击可新标签查看原图；代码块与数据表格支持横向滚动。
- **收藏与感谢**：话题右上角菜单可收藏或感谢作者；悬停在评论上可感谢该楼层（操作前会确认金币消耗）。
- **原站功能衔接**：通知中心、账户设置、未内置的投票/忽略/附言等高级操作，均提供“在新标签页打开原站”入口。

## 核心机制与安全设计

1. **同源请求与令牌保护**：
   - 所有数据请求沿用当前域名与浏览器 Cookies。
   - 发帖、回复、感谢前自动重新获取原站最新的 `once` 校验令牌，防止令牌过期提交失败。
2. **零第三方服务**：
   - 不引入任何外部服务器或第三方统计，不收集任何用户凭据或隐私。
3. **内容安全净化 (Sanitization)**：
   - 原站 HTML 内容和 Markdown 渲染结果在插入页面前均经过 [DOMPurify](https://github.com/cure53/DOMPurify) 深度净化，移除潜在恶意脚本与样式攻击。
4. **失败保护与幂等性**：
   - 绝不自动静默重试写入操作，避免重复扣币或重复发帖。
   - 提交失败时保留草稿输入框内容，并提供直达原站对应页面的处理链接。

## 适用范围与限制

- **分辨率适配**：专为桌面端设计，视口宽度需 ≥ 1024px；屏幕过窄时自动回退为 V2EX 官方布局。
- **适配路径**：适配 `www.v2ex.com` 和 `v2ex.com` 的首页、`/go/*` 节点页、`/t/*` 话题详情页以及 `/my/topics`。其他偏门页面保留原站样式。
- **原站接口变动**：脚本依赖原站 DOM 结构解析。若 V2EX 官方调整页面结构，未识别的动作将降级为“使用原页面打开”。

## 本地开发与测试

本项目采用 TypeScript + esbuild 构建，零运行时 CDN 依赖，内置 Playwright 端到端仿真测试。

### 常用命令

```bash
# 1. 安装项目依赖
npm ci

# 2. 编译打包生成 v2ex-wechat.user.js
npm run build

# 3. 监听源码变动实时构建
npm run dev

# 4. TypeScript 类型检查
npm run typecheck

# 5. 运行完整自动化测试 (构建 + 20 项 Playwright 仿真测试)
npm test

# 6. 一键全面校验 (类型检查 + 自动化测试)
npm run check
```

### 测试说明
- 测试运行在 Playwright 隔离的 Chromium 环境中。
- 测试使用本地 Mock 构造的 V2EX HTML 夹具并拦截所有网络请求，覆盖楼层跳转、草稿持久化、令牌刷新、XSS 净化以及 1280px / 1440px / 2048px 布局无溢出断言。
- 测试**不会向真实 V2EX 站点发送任何写入请求**，不消耗金币。

├── .github/              # GitHub 配置文件与工作流
